# 内置中式界面字体

字体为 **Noto Serif SC（思源宋体）500 字重**的网页子集，由 Google Fonts 的公开字体服务按 310 个请求字符生成，内容为原有通用界面用字、示例标签、拉丁字符，以及李白《早发白帝城》的全文、标题和作者，文件大小为 53,928 字节。相对上一份子集增加 23 个请求字符、3,940 字节。

用于品牌文字、标题、诗词与模块名称。操作导航和正文使用清晰的系统黑体，指标数字沿用数字字体；未收录的字符由本机宋体或通用衬线字体补足。使用 `font-display: swap`，不等待字体下载才显示内容，运行时不访问外部字体服务。
