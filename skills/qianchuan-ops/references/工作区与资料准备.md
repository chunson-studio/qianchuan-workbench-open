# 工作区与资料准备

先读根目录 `AGENTS.md` 与用户现行的工作区索引，再按账户、日期和主题找到正在使用的文件；没有现行索引时，才参考[工作区索引模板](../assets/workspace/工作区索引.template.md)。能承接本次任务的文件直接更新，不因模板另建第二份“当前版”。只有首次建立工作区，才参考下列布局；按需要创建，不一次生成空目录。

## 推荐布局与文件职责

| 位置 | 只放什么 | 适用边界 |
|---|---|---|
| `工作区索引.md` | 当前入口、文件路由、状态说明 | 不复制策略、阈值和长篇结论 |
| `账户策略/<账户名>/账户资料.md` | 事实来源、账户身份、商品和经营成本、资料缺项 | 记录来源和数据日期；未知保留待提供 |
| `账户策略/<账户名>/当前策略.md` | 已确认目标、约束、控制矩阵和授权边界 | 建议不能写成已确认策略 |
| `运行入口/` | 持续任务要读哪些文件、如何接续 | 只编排引用，不复制阈值；一次性任务不必建 |
| `任务卡/<account_id>/<日期>/<场次>/任务状态.md` | 本场身份、明确授权依据、源版本、回执、待办 | 没真实场次键就写“待确认” |
| `素材分析/<account_id>/<日期_主题>/` | `报告.md`、`数据/` 原始或清洗结果、`过程/` 缓存中间物、`脚本/` 一次性脚本 | 结论与输入分开，原始报表保持原样 |
| `复盘报告/<account_id>/<日期>/<场次>.md` | 使用[分析复盘模板](../assets/workspace/分析复盘.template.md)的终版结论 | 同场只留一个现行终版 |
| `账户知识/` | 经确认的方法、案例、研究路由 | 经验不升级成当前策略 |
| `tools/` | 确实跨任务复用的参数化工具 | 一次性脚本放对应分析或审计的 `脚本/`，缓存中间物放 `过程/` |
| `归档/` | 已失效版本和迁移备份 | 标明来源与失效原因，不作启动入口 |

账户 ID 未知时，离线项目可用用户明确的项目名；不能猜账户归属。报告、脚本和数据不散落根目录。旧附件可以记录原路径，不要求复制或搬动。模板只是填写骨架，不增加账户权限、写入能力或授权。

## 谁填写，缺什么才问

Agent先从当前消息、已有文件以及已获授权的接口或报表填已知项，并记录来源、读取时间和统计窗口。用户需要确认的是自身决定：商品成本、毛利、履约与售后成本，预算承受边界，业务目标，停止线，以及本次动作授权。建议值不能预填为已确认值；缺失写“待提供”或 `null`，不代表 0、无限预算或允许执行。

| 任务 | 先查或自动读取 | 确需用户提供/确认 | 缺失影响 |
|---|---|---|---|
| 规则问答 | 产品、规则卡、问题口径和时间范围 | 若上下文不明，确认对象与口径 | 可能只能给适用条件，不能断言结论 |
| 离线素材分析 | 报表覆盖日期、层级、素材/计划字段 | 比较目标、业务优先级 | 只能做指标描述，不能决定保留或放量 |
| 制定具体参数 | 历史报表、当前策略、已有操作记录 | 目标、预算/出价范围、停止条件 | 只能给候选方案，不能落单一参数 |
| 实时执行 | 当前对象状态、权限、写入与回读能力 | 动作范围和明确授权 | 不执行或只给人工步骤 |
| 保障核算 | 投放消耗、有效订单、目标、报表日期与层级、变价和定向历史 | 目标口径与模式（报表无法确认时） | 资格、分段次数或赔付金额待核验 |

订单与净成交口径、报表日期和层级、任务当前状态、变价/定向历史要分别处理，不能用一个汇总数字代替。先检查本地报表覆盖，能自动读取就不让用户抄数据。

## 主动补数流程

识别缺口后，先取已有资料和已授权可读数据；仍缺时只问当前最关键的一个问题，并说明用途及必要的数据范围，不要求上传全库、凭据或无关文件。用户答复后更新原文件的状态和来源。未回复时继续不依赖该字段的分析，把依赖项标为待补，不猜数据；同一缺口已问过就记录待补，不每 5 分钟重复催，只有到用户约定节点或出现新情况才提醒，也不自动创建定时器。

补数按当前任务层级推进，不能把两组问题塞成一张完整开户问卷。离线排序或暂停/追加候选，先取得当前统计期缺失的订单/成交口径以及用户采用的判断线；账号ID、实时任务状态和当前预算仅在对象归属确实不明、核定追加金额或执行时补齐。用户已有可接受ROI/CPA和停止条件时，可以先按这些线判断，不同时强制索取商品成本；只有要推导财务盈亏线或核算利润时，才需要商品、履约和售后成本。已经给出或从允许来源能读到的内容不再次索取。

## 文件寿命与收尾

核心事实、原始输入、现行策略和必要验证证据保留；同主题只保留一个当前结论。`过程/` 可放临时文件，任务结束时列出可再生成且无引用的缓存，获允许后再删除。删除或归档前检查引用、内容哈希和用途；归档写明失效原因。不能按扩展名或旧日期判定无用，保护区不进入整理。避免重复压缩包和重复解压目录。
