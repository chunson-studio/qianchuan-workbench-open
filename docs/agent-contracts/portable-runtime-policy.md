# Agent 决策与工具执行边界

本项目提供账户读取、计算和操作能力。是否执行、执行范围及需要补问的事项，由 Agent 依据用户当前任务判断。工作台不设置项目级只读、逐次确认或自动执行模式，也不因安装、接入或读到示例而自行启动投放。

主计划禁止删除。追投任务的删除授权不包含主计划；性能测试、连接恢复和通道切换不授予主计划写入权限。

## 经营决策归属

暂停、恢复、删除、新建数量及调参由Agent决定。脚本读取、计算、执行明确动作并核验结果；不得在读盘、公式计算或下播分支自行提交广告操作。临时措施只按用户指定的范围和期限生效；用户解除后同步当前授权，下一场不继承已结束的临时限制。

用户选择原始页面模式时，由Agent通过已核验的浏览器通道读取原始页面、计算和判断。脚本仅执行指定对象和参数的页面动作，Agent按原ID核验。沿用现有当前状态保存必要观测、参数基线和未决；与旧路径切换时先核原提交，不重放。

## 日常留档

2026-10-09用户取消例行逐轮存档与操作回执文件。正常轮次不写DOM/点击证据、轮次JSON、逐动作回执、决策台账或重复报告，也不为这些留档补查页面、切通道或追加工具调用。保留运行必需的当前状态、幂等请求标识、提交意图、未确认结果、执行互斥和反馈截止；未知不重发，不阻断其他独立工作。连续创建采用next_round时，由下一轮正常池读取处理原结果，不额外逐条/批后回查。这些内部状态由执行器维护，不要求Agent另写一份；用户要求的每轮对话汇报照常输出。

共享CUA reader和动作适配器默认不留详细档；仅用户明确要求诊断、验收或专项复盘时可设`diagnostic_archive:true`。内存观察引用以`memory:`标识，不能冒称存在证据文件。文件RPC受限备用的request/response/result是执行传输所需，不再叠加诊断副本；已能直接导入的会话优先复用直接入口。既有历史文件不自动删除，运行中的冻结模块不热替换。

## 兼容字段

execution_mode 统一返回 agent_decides。旧 recommendation_only、confirm_writes、auto_guarded、allow_* 和 QC_TRIAL_READ_ONLY 不再作为项目执行开关；旧草稿可读取，接入保存不覆盖既有账户策略。分析器返回的 recommendation_only / executable:false 仍表示该分析器只生成建议，不表示整个项目处于只读模式。

Agent 接续时读取用户任务、账户资料与实际对象。有显式 boost_write_scope 时，工具核对其中的账户、计划、场次、动作、目标和时效；没有该字段不要求先激活某个模式。接口自身的参数约束、平台能力和实时对象校验仍以实际 Schema 为准。

## 工具负责的正确性

- 每次显式绑定账户、广告户和目标；不能跟随前端选择或回落到其他账户。适用的动作同时绑定主计划、直播间和开播时间。
- 请求校验类型、单位、ROI 口径、目标归属及必要的当前状态；预算更新保留预期前值和并发冲突检查。
- 同一执行对象检查归属与并发；文件登记不是跨进程锁，更不是跨宿主锁。
- 创建请求按稳定 request_id 留存和去重。提交后超时、断线或回读失败是结果未知，不能换编号、换通道或改走 API 重发。
- 回执区分未提交、上游接受、变化已回读、未变化及待核验。只有有证据时才报告实际写入数；结果未知不填零。
- 本机访问与远程令牌校验属于服务访问控制，与 Agent 的投放判断分别处理。

通道优先级与切换条件统一见[通道选择与兜底](../项目架构与演进路线.md#通道选择与兜底)。CUA、dsh 宿主和本地 Playwright 使用独立绑定及证据。逐动作登记只按[浏览器按钮库](../浏览器按钮库.md)执行；本地入口见[本地 CDP 通道](../浏览器追投工具.md#本地cdp通道)。读取失败可以选择其他可用读取通道，提交结果未知时先核验原对象。

## 显式追投范围中的控制参数

| 字段 | 当前职责 |
|---|---|
| `concurrency.max_active_tasks` | 创建、恢复前核对该主计划完整列表的在投数量。未知状态、重复 ID、不完整分页及尚未观察到的未确认创建/恢复结果均阻断加量；已在投对象重复恢复不多占一个名额 |
| `concurrency.min_active_tasks` | 保存给 Agent 的目标下限；不触发后台补建，不阻碍暂停 |
| `elimination.room_floor_roi` | 仅限制新建；按同户、同房间、同开播时间的场次净成交 ROI 比较，缺失不补零 |
| `elimination` 的其他淘汰字段 | 保持原删除闸门语义，不套到暂停；是否允许删除仍由当前用户任务决定 |
| `carryover_task_ids` | 本场显式接管的同一中国日期旧任务 ID。未列入时，任务创建时间不得早于本场开播；不会自动把当日全部任务纳入 |
| `allow_post_live_delete` | 与本次明确删除授权、`allowed_actions`、精确 `action_target_ids.delete` 共同使用，已配置的动作期限须未过期。绑定房间已下播、同账户另一房间仍在播时，必须取得绑定房间同开播时间的唯一已结束场次及有效结束时间；仅允许指定的已暂停或“关联直播间未开播”任务，仍核验归属、平台能力和删除淘汰闸。不授予日常删除或跨场清理权限 |
| `allow_post_live_pause` | 仅对本次明确收尾任务开放：必须同时有`allowed_actions.pause`、精确`action_target_ids.pause`与未过期`action_expires_at.pause`。无论账户是否还有其他房间直播，都须核验绑定房间同开播时间的唯一已结束场次和有效结束时间。仍核验本场任务/显式接管清单、主计划及平台暂停能力；不授予恢复、新建、加预算或删除权限，不触发后台清场 |
| `judgment_basis`、`hysteresis_rules` | 向 Agent 暴露当前判断口径与滞回参数。建议计算见[Token 优化 SOP](../逆向API功能图.md)，配置本身不启动看门狗或调度 |

同一服务进程按账户、主计划串行执行范围预检到提交，随后按实际列表和操作回执重新核验数量。这不约束网页人工操作或其他进程，也不替代执行归属交接。未决记录只能靠证据核对，不能清空日志来绕过检查。

## 账户事实与数据质量

Profile 保存账户身份、经营目标、财务口径、校准基线、样本、可比条件和来源。未知保持 null，不能填零、套用其他账户数值或把历史案例当默认阈值。来源分别记录为 official、runtime_config、historical_calibration、human_confirmed 或 task_override，并保留更新时间。

读取先核对账户、主计划、场次、窗口和时间。支付、平台 1 小时净、最终结算、乘方综合 ROI 分列；平台累计 ROI 保留原值。同户同场同口径的连续快照才做差分，实际 7 分钟就写 7 分钟。过期、未加载、分页不完整或身份冲突的数据不能支撑依赖它的动作；不把这些错误转换成全项目的运行模式。

Agent 根据任务补齐必要证据：Profile → 在播状态 → 当前盘面 → 同口径差分 → 必要的专项读取。缺少某项校准只说明该判断证据不足，不制造统一的账户禁用状态。平台标签、算法分数和课程经验作为旁证，不能冒充已验证收益或因果。

## 执行与复盘

### 脚本故障与浏览器备用

所有直播调控对话取消整轮执行时限、固定等待秒数和耗时达标线；不能因运行时间长拒绝工作或跳过恢复。工具自身报错按故障处理，不能宣称它已取消上游动作。调度频率不作为本轮截止时间；真实在途调用继续接续，禁止重叠启动。

2026-10-09用户明确要求脚本失效时继续原授权调控，不得因脚本缺失、加载失败或单笔未知使整间停摆。正常轮优先脚本，故障限次恢复一次；仍失败时，在确认原调用已结束、无并发写入后，允许同一执行会话通过本场浏览器直接读取和操作。实时身份、经营条件、预算和任务范围不随备用方式改变；不因“手动”跳过原未知请求的防重。

浏览器编号不是固定身份。首次和重连核Profile、可用的extensionInstanceId，以及两页广告户、主计划、房间和开播时间；配置仅更新本场已核连接字段。不得依靠“第一个Chrome”、当前前台页或历史browserId选对象。不同标签或分组不证明登录态/执行连接隔离。

controller46/reader28已取消持久会话锁：不再创建、读取或恢复execution.lock/capture.lock，旧state.owner不授予或阻止本场执行。按账户、主计划、房间、开播与实时页面核本场；旧场未知自动隔离，不要求旧场结案、owner释放或recordSceneIsolation，不占本场新建容量。原请求不重发，当前场的防重与真实浏览器占用仍分别处理。 account_plan_busy/reader_already_running在新版仅指本地仍在执行的调用；沿同一个Promise接续。原调用结束后整组重载；本会话环境确实损坏才调用mcp__cua_repl.js_reset，重置后先按工具说明初始化和重新绑定。原平台请求不因此取消。真实浏览器跨会话占用先核是否错绑，不能强抢别的直播间。脚本仍失败则按已授权直接浏览器备用继续。

单笔结果未知仅隔离原请求和原目标，不清空、不改成成功/失败、不重发；继续本场读取和其他独立目标。未知新建仍占潜在供给与授权预留，不重复补同一缺口。直接浏览器动作按真实结果汇报并注明手动备用，不伪造控制器回执；重新接回脚本时从当前任务池读取接续，不重放手动动作。备用不授予跨账户操作、暂停主计划或更改其他会话调度的权限。

对已经接管并获授权的操作，Agent 完成判断后直接调用对应入口执行和回读，不把行动要求降为建议，也不重复询问已有授权。用户指出当前任务的问题时，先查相关规则、已有范围及实时证据，完成范围内修正。仅要求解释或明确只读的任务不由此转为写入；确有缺失且无法自动取得的信息才补问。能力缺失、冲突或未决先处理具体阻塞并如实反馈，不伪报执行，不通过修改账本或更换请求号绕过。

执行前核对当前用户范围、对象及参数，执行后当场回读目标。没有变化或效果不明时保留必要内部状态；文件留档按[日常留档](#日常留档)。观察窗口内的收益与损耗按账户口径验证；只有明确要求复盘或沉淀经验时整理账户记录，跨账户通用结论需要独立验证。

部署与接入不启动后台采集、定时任务或投放。持续调度按[定时与循环任务](../定时与循环任务.md)绑定账户、频率与持续范围。健康检查是一次检查，不自动创建常驻巡检。
