## 安装

下载仓库或 Git 克隆后在本地打开项目。Windows 可双击根目录「开始使用.cmd」。支持本地执行的 Agent 可按 AGENT_START.md 自动检查安装；手动运行 `npm ci`、`npm --prefix server-app ci`、`npm start`。打开命令返回的本机 URL。

## 账户与参数

首次为空账户。使用者本人网页登录，Agent 核验身份后走本机接入流程。已有账户续接，不重复开户。凭据只留本机，不能提交到仓库或粘贴进群聊。自己的目标、预算、ROI口径及触发条件保存至私有工作区；本版不提供作者策略和推荐阈值。

## 通道

- 页面读取与操作：选择宿主现有浏览器能力、原生 Playwright 或官方 CLI；扩展凭据在本机私有配置中管理。
- 历史、素材、原始报表：使用本机 API 工作台；接口失败返回未知，不自动换账户。
- 后台：显式启动独立进程并用客户端复用；按账户隔离状态。重连先核原页面及未决，不重放未知提交。
- 每次调用显式指定账户、主计划、场次和对象；同一个任务只由当前获授权的会话执行。

## 一轮执行

核身份与场次 → 读完整原始数据 → 按使用者自己的规则决定 → 提交明确动作 → 原对象回读。主计划不删除，任务默认名称不改。总数变化、页面失效和未知提交要显式报告。

## 验收

先运行 `npm test`。真实账户先测读取，再测使用者授权的动作与回读，最后测后台、断线恢复和多账户。完整一轮的计时必须包含读取、判断、执行与回读。没有实际业务证据不能称全部通过。
