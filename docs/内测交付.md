# 交付与维护

本仓库以[千川工作台免费自用许可证](../LICENSE)公开通用执行能力，允许自有店铺免费使用，禁止转卖、收费部署、代运营和收费平台。范围见[公开说明](../审核说明.md)，使用入口见[AGENT_START](../AGENT_START.md)。没有付费锁或试用期限不表示不受许可限制。

## 本机构建

使用锁定依赖安装并执行 `npm test`。`python tools/build_release.py --check` 验证 PUBLIC_MANIFEST.json 中的文件与哈希；`python tools/build_release.py --output <新建压缩包的绝对路径>` 仅打包清单内文件。运行资料、依赖目录和 Git 历史不进入压缩包。

## 放行条件

凭据与个人资料检查、模块依赖检查、离线回归和空账户启动均通过。业务策略由使用者提供，作者实盘配置和记录不分发。离线测试与真实账户验收分别记录，具体结果见 [验证记录](../VERIFICATION.md)。

## 全新客户验收

Agent 读取项目入口并检查依赖。使用者本人登录千川；核对账户、主计划、场次及现有任务。先验证读取，按当前明确任务进行最小操作并回读。未知提交核原请求，不自动重放。不删除主计划，不改任务默认名称。

## 维护与版本更新

### 更新现有说明

变更时同步入口、脚本索引、项目 Skill 和测试。通用规则仅维护一份正文；使用者参数保存在本机工作区。

### 验证与分发

保留原始值、时间、数据口径和完整性；不把未知写成零。多账户显式绑定且相互隔离，换场或换通道先核身份和未决请求。

#### 项目整洁与测试产物

源代码历史由 Git 管理。测试使用独立临时目录和合成数据，不能连接个人浏览器或账户。专项诊断证据留在本机；清理仅限核验过的本次生成目录，不覆盖客户资料。

#### 必要验证与交付

执行受影响测试后运行公开版完整回归；独立启动空账户服务，检查界面、CLI 和后台恢复相关用例。最终说明区分实现、离线验证与真实业务验收，不把测试通过描述为所有账户均可用。
